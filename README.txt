Academic homepage for Dibyasri Barman

Files
  index.html   the page
  style.css    all styling (light and dark themes, mobile layout, print layout)
  assets/Dibyasri_Barman_CV.pdf   the CV linked from the "CV (PDF)" button
  assets/dna-bg.js   animated DNA helices drawn in the side margins on wide screens
  assets/profile.svg placeholder portrait (replace with a real photo)

To view: open index.html in a browser.
To publish: upload the whole folder to any static host (GitHub Pages, Netlify, a university web space).
There are no external fonts, so the page itself works offline.
The only external script is Google Tag Manager (container GTM-MK2WHKRZ), loaded in the <head> of index.html for analytics.

Before publishing
  - Replace assets/Dibyasri_Barman_CV.pdf with a copy compiled from the .tex with the real icon package.
  - Confirm the personal email address in the Contact section.
  - Add a square photo (at least 440x440 px), e.g. assets/photo.jpg, and point the <img> in the header at it.
