Academic homepage for Dibyasri Barman

Files
  index.html   the page
  style.css    all styling (light and dark themes, mobile layout, print layout)
  assets/Dibyasri_Barman_CV.pdf   the CV linked from the "Download CV" button

To view: open index.html in a browser.
To publish: upload the whole folder to any static host (GitHub Pages, Netlify, a university web space).
There are no external fonts, scripts or trackers, so it works offline.

Before publishing
  - Replace assets/Dibyasri_Barman_CV.pdf with a copy compiled from the .tex with the real icon package.
  - Confirm the personal email address in the Contact section.
